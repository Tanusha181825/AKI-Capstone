# AKI-Capstone

Person 2's local preprocessing pipeline for approved MIMIC-IV structured measurements and medication administration. The code does not create cohorts/KDIGO labels, predictions, models, notes, or eICU data. No patient data is included in this repository.

See [docs/person2-preprocessing.md](docs/person2-preprocessing.md) for mapping review, local setup, schemas, sample runs, and limitations.
